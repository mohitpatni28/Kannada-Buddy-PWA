# Kannada Buddy

A personal, mobile-first Kannada learning PWA for everyday Bengaluru situations: autos, food, shops, UPI, apartment staff, security, and quick small talk.

## What is included

- Next.js app router project ready for Vercel
- Installable PWA manifest and service worker
- Curated 30-phrase Bengaluru survival seed deck
- 621 raw Wikivoyage Kannada phrasebook candidates generated by importer
- Today lesson with new phrases, review prompts, listening quiz, and mission
- Travel mode with browser speech synthesis
- Searchable phrasebook with approved phrases first
- Local confidence review scheduling
- Library and admin screens for approving, rejecting, and editing phrase candidates
- Sources and licenses page for future open-content imports

## Run locally

```bash
pnpm install
pnpm dev
```

Then open:

```text
http://127.0.0.1:3000
```

## Build

```bash
pnpm build
```

## Import Wikivoyage

```bash
node scripts/import-wikivoyage.mjs
```

The importer reads the Wikivoyage Kannada phrasebook through the MediaWiki API and writes `data/wikivoyage-phrases.ts`. Imported phrases are marked `raw_imported`, `source: "wikivoyage"`, and `license: "CC BY-SA"` so they can be reviewed before entering lessons.

## Notes

The v1 app is local-first. Review progress and admin edits are stored in the browser, not synced to a server yet.

The next best upgrades are export/import backups, a Tatoeba importer, and cloud TTS caching for the top phrases.
